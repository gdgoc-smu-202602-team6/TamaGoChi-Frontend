# UI·설정 구조 정리 (2026-11-04)

사용자의 최신 피드백에 따라 게임의 방·캐릭터 구성은 유지하고 앱의 정보·탐색 UI를 정리했다. 이전 시안의 큰 로고와 강한 색·테두리를 그대로 복제하지 않는다. 기능 명세·권한·오류/재시도·공부 및 배치 저장 계약은 유지한다.

## 화면

- 앱명은 시작 시 약 1.5초 표시한다. 네이티브 시작 화면은 배경만 표시하고 앱 오버레이에서 이름을 보여준다. 네이티브 설정 변경은 다음 바이너리 빌드부터 적용된다.
- 내부 화면은 작은 제목과 아이콘을 사용한다. 공통 카드·버튼은 얇은 경계, 블루 그레이·라벤더·민트·아이보리 팔레트를 사용한다.
- 내 Bolt·Level/XP는 마이 프로필에서 확인한다. 홈·공지·상점의 반복 게임 헤더는 제거했다. 상점 가격·해금 레벨과 친구의 레벨 표시는 기능 정보이므로 유지한다.
- 공부 시작은 원형 재생 아이콘이다. 공부 중·결과 화면의 홍보성 부제와 반복 보상 설명도 줄였다. 실행/복구/처리 중 접근성 이름과 중복 실행 방지는 기존 상태를 따른다. 보상 공식·홍보 문구를 제거했으며 출석·버그 진행 정보는 남긴다.
- 친구 목록/방 방문의 상단 복귀는 44×44 아이콘이다. 새로고침도 아이콘으로 표시한다.
- 방 편집은 선택 안내창·선택 테두리를 제거했다. 물건의 직접 드래그, 접근성 선택 정보, 취소 복원·최종 이동 좌표 반영·저장 전 이탈 확인은 유지한다.

## v4 시각 컨셉 복원 (2026-11-04 후속)

정리한 구조는 그대로 두고 회색·라벤더 위주였던 앱 UI 색을 v4 목업의 게임 컨셉으로 되돌렸다.

- 토큰(`theme.ts`): 하늘색 배경, 크림·흰 표면, 네이비 2px 외곽선과 3px 바닥, 노랑·초록·빨강 강조, 오류 표시 `GameUi.errorText`. 분류·파트 색(`palette.ts`)과 가구·소품 임시 에셋 색(`asset-palette.ts`)도 같은 기준으로 바꿨다.
- 공통 컴포넌트: `GameCard`·`GameButton`(아이콘·배지, 눌림)·`IconButton`(흰 사각)·`SettingsSection`·칸 나뉜 `ProgressMeter`·`SegmentedTabs`(상점·방 꾸미기 공용)·`PixelNumber`(픽셀 숫자)·하단 탭(네이비 바·노란 선택).
- 화면: 홈은 방 아래 모서리에 방명록·방 꾸미기, 헤더에 친구 방을 둔다. 공부 중은 네이비 별 배경에 캐릭터와 픽셀 타이머, 결과는 보물상자·STAGE CLEAR·픽셀 Bolt·보상 칩으로 보여준다. 공지 필터는 선택 시 네이비, 상점은 등급별 썸네일 색과 잠금 시 네이비 버튼을 쓴다.
- 뒤로가기 통일: 방명록·동아리 가입/만들기·가입 신청·부원·파트·공지 분류·공지 쓰기/수정의 `◀ …` 텍스트 버튼을 상단 아이콘 헤더로 바꿨다. 공지 쓰기·수정의 등록/저장 버튼은 헤더 오른쪽에 그대로 둔다.
- 기능·서비스·권한·문구 계약은 바꾸지 않았다. 상점 잠금 버튼 문구만 `LV.n 필요`에서 `LV.n 해금`으로, 홈 출석 안내는 `출석까지 n분`으로 줄였다. 홈의 공부 버튼 접근성 이름과 상태는 그대로다.
- 고정 상단 바: 모든 내부 화면의 `ScreenHeader`를 스크롤 영역 밖으로 옮겨 배경색 바로 고정했다. 아이콘은 테두리 없는 44×44 선 아이콘이며, 내 방은 친구 방·방명록(새 글 수 배지)을 바에 둔다. 상점 분류 탭과 공지·친구의 동아리 밑줄 탭도 바 안에 둔다. `GameScreen`도 같은 바를 쓰며 앱 차단 안내의 긴 복귀 버튼을 바의 뒤로가기로 바꿨다.
- 공지 위계: 동아리(바의 밑줄 탭) → 분류 칩 → 세부 분류 칩(작고 옅은 칩) → 카드 순으로 크기와 강조를 나눴다.
- 검증: 타입 검사·린트·기존 테스트 388개 통과. Mock Web 개발 서버에서 홈·공지·상점·마이·친구·방 꾸미기·설정·방명록·동아리 가입·로그인·공부 시작→공부 중→결과를 320×568·390×844·1280×844로 확인했다. Android/iOS 실기기와 `NativeTabs` 색 반영, `app.json`의 시작 화면 배경색(다음 바이너리 빌드부터 적용)은 확인하지 않았다.
