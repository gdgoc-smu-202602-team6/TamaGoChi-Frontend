## 남은 큰 작업 6개

| 순서 | 작업 묶음 | 아직 필요한 내용 | 의존성·확인 사항 |
| --- | --- | --- | --- |
| 1 | 친구 방·좋아요 | 동아리 부원 목록에서 본인 제외·공부시간 순 정렬·방/통계 batch 조회·방 방문·좋아요 | 같은 동아리 접근 제한, 사용자 단위 좋아요, 기존 방 렌더러 재사용 |
| 2 | 방명록 | 내 방의 전체 방명록·동아리별 방문 방명록·작성/삭제·새 글 표시 | 작성자/방 주인 삭제 권한, 동아리별 노출, 내 방 새 글 확인 시각 |
| 3 | 개인 설정 보완 | 닉네임 변경·계정 탈퇴·내 소속 파트/동아리 알림 설정·보유 아이템 수·마이 장착 표현 | 계정 탈퇴의 `last-manager`, 다른 기능과 계정 상태/개인 데이터 갱신. 운영진의 타인 파트 변경은 현재 계약에서 허용하지 않아 조율 필요 |
| 4 | 알림·인증 보완 | 기기 토큰 등록/삭제·푸시 수신/진입·읽지 않은 수 배지·메일/모바일 callback 검증 | 실제 기기·푸시 설정 필요. Google/Kakao는 백엔드 공급자·callback 준비 후 연결 |
| 5 | 공부 중 앱 차단 | 플랫폼 방식 검토·앱 선택/권한·공부 세션과 차단 시작/종료·복구 | Android/iOS 별도 검토와 development build 검증 필요. 현재 UI는 차단 중이라고 표시하지 않음 |
| 6 | 최종 표현·안정화·출시 | 최종 캐릭터/가구/아이콘/폰트 교체·벽 물건 배치·Metro SSR 오류·접근성·실계정/실기기·빌드/배포 준비 | 팀 에셋 제공, [벽 배치 계약](room-wall-placement-contract.md) 합의, 실제 기기와 계정·배포 설정 |

작업을 화면·API·통합 단위로 나누면 대략 **9~14단계**로 계획할 수 있다. 이는 일정 확정치가 아닌 현재 범위의 분할 추정이다. 앱 차단·실기기 검증·에셋 교체는 크기가 큰 작업이며, 플랫폼과 팀 자료 준비 상태에 따라 추가 단계가 생길 수 있다.

다음 구현 순서는 친구 방·좋아요 → 방명록 → 개인 설정 보완을 기준으로 잡는다. 알림·인증·앱 차단은 실제 기기와 외부 설정을 확인하며 진행하고, 각 단계에서 문서·타입·린트·필요한 테스트와 실행 검증을 갱신한다.
